Tests para las jugadoras

Crea un test con preguntas para todas, solo para exteriores o solo para interiores. Las preguntas fijas les salen a todas las que les toquen por su grupo (mismas preguntas); el resto va a un sorteo y a cada una le salen otras distintas. Si una jugadora juega de exterior e interior, la marcas en las dos y hace un solo test con las preguntas de ambas. Cada jugadora lo responde una vez y tú ves quién lo hizo, quién no, qué contestó y dónde falló.

Nuevo test

0 = sin límite. Con tiempo, a la jugadora le sale una pregunta cada vez, no puede volver atrás y cuando se acaba el tiempo pasa sola a la siguiente (si no contestó, cuenta como fallada). Así no les da tiempo a buscar. En cada pregunta puedes poner un tiempo distinto.

Marca Exterior, Interior o las dos. Se guarda al tocar y vale para todos los tests. Las que no tengan ninguna solo harán las preguntas de «Todas».

Pegar varias preguntas de golpe

Una pregunta por bloque, con una línea en blanco entre bloques. La primera línea es la pregunta, las siguientes son las opciones y la correcta empieza por *.
